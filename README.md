# AutoScout

Simple run guide.

## Start Backend

```bash
cd "/Users/yaoyutong/Documents/FYP/AutoScout/backend/code"
python3 api_server.py
```

Open a second terminal and run:

```bash
cd "/Users/yaoyutong/Documents/FYP/AutoScout/frontend"
python3 -m http.server 5500
```

## Open in Browser
